# Código De Conduta

## Propósito

Este projeto deve manter um ambiente técnico, respeitoso e focado em colaboração. Discussão crítica é bem-vinda quando estiver ligada ao código, arquitetura, segurança, testes, documentação ou produto.

## Comportamento Esperado

- Tratar outras pessoas com respeito.
- Discordar com argumentos técnicos claros.
- Aceitar revisões como parte normal do processo.
- Manter issues e pull requests objetivos.
- Evitar informações privadas, credenciais ou dados reais em discussões públicas.

## Comportamento Inaceitável

- Assédio, insultos, ameaças ou ataques pessoais.
- Discriminação ou linguagem sexualizada.
- Exposição de dados privados sem autorização.
- Spam, autopromoção irrelevante ou discussões fora do escopo.
- Pressão para ignorar segurança, licença, testes ou revisão.

## Aplicação

Mantenedores podem editar, ocultar, fechar ou remover comentários, issues, pull requests e contribuições que violem este código. Casos graves podem resultar em bloqueio de participação no projeto.

## Reporte

Reporte problemas de conduta por issue apenas quando o conteúdo puder ser discutido publicamente. Para casos sensíveis, use o canal privado definido pelos mantenedores do repositório.

## Atribuição

Este código é uma versão enxuta inspirada no Contributor Covenant, adaptada ao contexto deste projeto.
